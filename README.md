# MOTIVA - Intelligent Sales Analyzer

Herramienta en desarrollo, que utiliza parte del análisis de datos desarrollada en Python y Pandas para automatizar el procesamiento de ventas, control de inventario y cálculo de métricas financieras del emprendimiento de indumentaria .

## Características
- Limpieza automática de archivos CSV con cabeceras irregulares y filas vacías.
- Procesamiento vectorizado con Pandas para optimizar el rendimiento.
- Cálculo automático de:
  - Facturación total y ganancia neta.
  - Volumen de prendas vendidas y transacciones.
  - Margen de ganancia promedio.

## 🛠️ Tecnologías utilizadas
- Python 3.x
- Pandas
